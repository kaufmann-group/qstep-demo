# QSTEP Demonstration
GitHub repository containing D-wave Ocean software demonstration for the Quantum Science, Technology, and Engineering Workshop at Purdue. `D-wave Demonstration.ipynb` contains the tutorial outlined in the presentation and `Additional D-wave Topics.ipynb` covers topics and problems not discussed at the workshop.

Please contact [Dhruv Upreti](mailto:dupreti@purdue.edu) for any further questions. This presentation was supported by [D-Wave Quantum Inc](https://www.dwavequantum.com/).
