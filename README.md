# QSTEP Demonstration

GitHub repository containing D-wave Ocean software demonstration for the Quantum Science, Technology, and Engineering Workshop at Purdue. The slides for the presentation is linked [here](). The `D-wave Demonstration.ipynb` jupyter notebook contains the tutorial outlined in the presentation and the `Additional D-wave Topics.ipynb` notebook covers topics and problems not discussed at the workshop.

This work was created by [Dhruv Upreti](mailto:dupreti@purdue.edu) and was supported by [D-Wave Quantum Inc](https://www.dwavequantum.com/).
