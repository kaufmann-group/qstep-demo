# QSTEP Demonstration

GitHub repository containing D-wave Ocean software demonstration for the Quantum Science, Technology, and Engineering Workshop at Purdue. The slides for the presentation is linked [here](https://purdue0-my.sharepoint.com/:p:/g/personal/dupreti_purdue_edu/IQCabNVUHYGxSogMtXEbLlMoATQRPXtEjgYG9-Sb9Fblhoo). The `D-wave Demonstration.ipynb` jupyter notebook contains the tutorial outlined in the presentation and the `Additional D-wave Topics.ipynb` notebook covers topics and problems not discussed at the workshop.

This work was created by [Esha Sury](mailto:esury@purdue.edu), [Aritro Chatterjee](mailto:chatte65@purdue.edu) and [Dhruv Upreti](mailto:dupreti@purdue.edu) and was supported by [D-Wave Quantum Inc](https://www.dwavequantum.com/).
